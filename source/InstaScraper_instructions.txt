To allow the script to use your existing Instagram login session, you 
	need to provide it with your sessionid cookie. Here's how to 
	find it in Google Chrome (the process is similar in other browsers).

1. Open Instagram

Go to https://www.instagram.com and make sure you are logged in.

2. Open Developer Tools

Right-click anywhere on the page and select "Inspect" from the menu.
	This will open the Developer Tools panel.

3. Navigate to the "Application" Tab

In the top bar of the Developer Tools panel, look for a tab named
	"Application". If you don't see it, you might need to click the
	>> icon to show more tabs.

4. Find the Cookies

In the "Application" tab, look at the left-hand sidebar. Expand the
	"Cookies" section, and you should see https://www.instagram.com.
	Click on it.

5. Locate the sessionid Cookie

A table of all the cookies for Instagram will appear. Look for the row with
	the name sessionid.

6. Copy the Value

Click on the sessionid row. In the cookie details below (or in the "Value"
	column), you will see a long string of characters.
	This is your session ID.

Double-click this value to select all of it, then copy it. This is what you
	will paste into the script when it asks.

Important Security Note:
	Your sessionid cookie is like a temporary password. Do not share it
	with anyone. The script only uses it on your own computer to access
	your account securely.
